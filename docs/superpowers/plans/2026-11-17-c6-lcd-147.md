# C6 Touch LCD 1.47 implementation plan

**Goal:** Install a usable USB-controlled Taby animation port on the owner's board.
**Spec:** [Approved design](../specs/2026-11-17-c6-lcd-147-design.md).
**Architecture:** Separate C6 ESP-IDF application; reuse portable upstream command
logic, use vendor LCD initialization and a bounded internal-RAM animation decoder.
**Tech stack:** ESP-IDF 5.5.2, C, Python 3.12, Pillow 12.0.0, esptool 4.11.0.

## Constraints

- Exact board ESP32-C6-Touch-LCD-1.47-M, 8 MB flash; no PSRAM.
- Preserve upstream S3 behavior and official installation contract.
- Firmware backup stays private outside Git. No whole-chip erase or eFuse writes.
- USB first; GIF-derived talking replaces Rive. No claims of full app compatibility.
