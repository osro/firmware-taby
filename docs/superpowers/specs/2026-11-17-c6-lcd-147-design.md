# USB-first Taby for Waveshare C6 Touch LCD 1.47

Approved by the owner in chat on 2026-11-17: “do it”, following the reduced
USB-first proposal. Exact board: ESP32-C6-Touch-LCD-1.47-M, JD9853 172×320 LCD,
AXS5106L touch, ESP32-C6FH8 and 8 MB flash. The M suffix denotes pin headers.

## Scope and architecture

Add an isolated ESP-IDF application at `firmware/targets/c6-lcd-1.47` so the
official S3 builds and installer remain unchanged. Reuse Taby's portable USB
command resolver, state machine and bounded line reader. Replace its
PSRAM-dependent graphics with offline-resized, palette/RLE frames decoded into
one internal-RAM RGB565 buffer. Store the curated animation pack in a separate
read-only flash partition, with generated offsets and bounds checks. Use the
manufacturer's JD9853 driver with attribution and documented C6 pin assignments.
Read touch over I2C; retain tap and hold polling commands.

The first version provides idle, listening, prerecorded talking, working,
searching and confirmation animations, plus other clips if the pack fits.
No Wi-Fi, Bluetooth, live Rive lip-sync, account provisioning or full reusable
UI cards. Report a distinct development hardware target and version, and do
not advertise capabilities that are absent. Desktop app compatibility must
be tested separately, not inferred from USB command acceptance.

## Validation and installation

Test the real C frame decoder against hand-checked malformed/valid fixtures
and Python-generated frames; keep upstream protocol tests passing. Build with
ESP-IDF 5.5.2 for ESP32-C6. Before writing, save the original complete 8 MB flash
outside Git, hash it and keep it private. Check chip and capacity, then flash
only the development bootloader, partition table, application and assets.
Do not erase the whole chip, modify eFuses, or force a mismatched chip.

After installation, query INFO, switch clips, check playback frame counters
and free heap over repeated changes, verify touch counters on real input,
and ask the owner to check the actual screen. Record partial verification
honestly if physical touch or visual feedback remains pending.
